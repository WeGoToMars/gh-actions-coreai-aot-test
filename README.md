# Core AI AOT on GitHub-hosted macOS

Step-by-step experiments with the free public-repository `xcode-27` runner.
Target: LiquidAI/d1-3B, using Tinkerbox's existing compiler, watchdog and full
ANE-placement verification. No paid runners are used.

The first experiment records the environment, Core AI compiler availability,
disk telemetry, and a Core AI device-architecture probe before and after
installing the Metal Toolchain. Later experiments and measured results will be
added after examining its logs.
